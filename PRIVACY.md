# Politique de confidentialité

PokeStat Challenge ne demande pas la création d'un compte et ne collecte pas volontairement de données personnelles.

L'application accède à Internet pour récupérer des données et illustrations nécessaires au jeu. Ces éléments peuvent être conservés dans le stockage privé de l'application afin d'accélérer les utilisations suivantes.

Aucun outil publicitaire ou analytique n'est intégré dans la version 1.0.0.

Pour toute question relative à cette politique, utilise la section Issues du dépôt officiel.
