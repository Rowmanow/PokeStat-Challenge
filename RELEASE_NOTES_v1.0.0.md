# PokeStat Challenge Android v1.0.0

Première version publique Android de PokeStat Challenge.

## Inclus

- Stat Draft
- Stat Guesser
- Français et anglais
- Filtres par types, générations et formes
- Méga-Évolutions et formes régionales
- Récapitulatif et combo optimal dans le Draft
- Interface tactile et cache local

## Installation

Télécharge l'APK joint à cette release, ouvre-le sur un appareil Android, puis autorise temporairement l'installation depuis la source utilisée.

## Bêta publique

Merci de signaler les problèmes dans l'onglet Issues en indiquant le modèle du téléphone, la version Android, la langue, le mode, les filtres et les étapes de reproduction.
