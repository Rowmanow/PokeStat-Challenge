# PokeStat Challenge v1.0.0

Première version publique de PokeStat Challenge pour Android et Windows.

## Télécharger le jeu

### Android

Téléchargez :

`PokeStat-Challenge-Android-v1.0.0.apk`

Ouvrez ensuite le fichier sur votre téléphone Android et autorisez temporairement l’installation depuis la source utilisée.

### Windows

Téléchargez :

`PokeStat-Challenge-Windows-v1.0.0.zip`

Ensuite :

1. Décompressez entièrement l’archive ZIP.
2. Ouvrez le dossier extrait.
3. Installez Python 3.10 ou une version plus récente si nécessaire.
4. Ouvrez un terminal dans le dossier.
5. Exécutez :

   `py -3 -m pip install -r requirements.txt`

6. Double-cliquez sur :

   `Pokestat-Challenge.vbs`

Ne lancez pas le jeu directement depuis l’archive ZIP. Il faut d’abord extraire tous les fichiers.

## Modes de jeu

### Stat Draft

Composez une équipe de six Pokémon en attribuant une statistique différente à chacun. Le récapitulatif compare votre résultat au meilleur ou au plus faible combo possible.

### Stat Guesser

Retrouvez les six statistiques de base d’un Pokémon en un nombre limité de tentatives.

## Fonctionnalités

- Français et anglais
- Filtres par types
- Filtres par générations
- Pokémon standards
- Méga-Évolutions
- Formes d’Alola, Galar, Hisui et Paldea
- Tirage uniforme parmi les candidats autorisés
- Récapitulatif stratégique du Draft
- Interface tactile sur Android
- Lanceur silencieux sous Windows

## Signaler un problème

Utilisez l’onglet Issues et précisez :

- votre appareil ;
- votre version Android ou Windows ;
- le mode utilisé ;
- les filtres sélectionnés ;
- les étapes pour reproduire le problème ;
- une capture d’écran si possible.
