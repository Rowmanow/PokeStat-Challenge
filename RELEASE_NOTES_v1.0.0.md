# PokeStat Challenge v1.0.0

Première version publique de PokeStat Challenge pour Android et Windows.

## 📱 Télécharger pour Android

Téléchargez :

**PokeStat-Challenge-Android-v1.0.0.apk**

Puis :

1. ouvrez le fichier APK sur votre appareil Android ;
2. autorisez temporairement l’installation depuis la source utilisée ;
3. installez PokeStat Challenge.

## 🖥️ Télécharger pour Windows

Téléchargez :

**PokeStat-Challenge-Windows-v1.0.0.zip**

Puis :

1. décompressez entièrement l’archive ZIP ;
2. ouvrez le dossier extrait ;
3. installez Python 3.10 ou une version plus récente si nécessaire ;
4. ouvrez PowerShell dans le dossier ;
5. exécutez :

   `py -3 -m pip install -r requirements.txt`

6. double-cliquez sur :

   `Pokestat-Challenge.vbs`

> Ne lancez pas le jeu directement depuis l’archive ZIP. Décompressez d’abord tous les fichiers.

## Modes de jeu

### Stat Draft

Composez une équipe de six Pokémon en attribuant une statistique différente à chaque Pokémon. Le récapitulatif compare votre résultat au meilleur ou au plus faible combo possible.

### Stat Guesser

Retrouvez les six statistiques de base du Pokémon en un nombre limité de tentatives.

## Fonctionnalités

- Français et anglais
- Filtres par types, générations et formes
- Pokémon standards
- Méga-Évolutions
- Formes d’Alola, Galar, Hisui et Paldea
- Tirage uniforme parmi les candidats autorisés
- Récapitulatif stratégique du Draft
- Interface tactile sur Android
- Lanceur silencieux sur Windows

## Quel fichier télécharger ?

- Android : fichier `.apk`
- Windows : fichier `Windows-v1.0.0.zip`

Les fichiers `Source code (zip)` et `Source code (tar.gz)` sont générés automatiquement par GitHub et ne correspondent pas aux versions prêtes à lancer.
