# PokéStat Challenge Mobile v1.0.3

## 🇫🇷 Français

### Nouveautés

- Ajout du mode Draft **« Le plus proche »**
- Victoire lorsque le score final se trouve à **±20 points de l’objectif**
- Ajout des nouvelles Méga-Évolutions de **Pokémon Légendes : Z-A**
- Prise en charge des formes Méga **X, Y et Z**
- Nouveau filtre de formes :
  - Standards
  - Méga
  - Régionales
- Le filtre **Régionales** regroupe les formes d’Alola, de Galar, de Hisui et de Paldea
- Mise à jour du numéro de version affiché sur l’accueil

### Évolutions intégrées depuis la v1.0.0

- **v1.0.1** : ajout de la règle **« Le plus proche »** dans le mode Draft. Le but est de se rapprocher au maximum de l’objectif. La victoire est accordée lorsque l’écart final est inférieur ou égal à 20.
- **v1.0.2** : ajout des Méga-Évolutions introduites dans Pokémon Légendes : Z-A.
- **v1.0.3** : regroupement des formes d’Alola, de Galar, de Hisui et de Paldea dans un filtre unique nommé **Régionales**.

### Mise à jour depuis la v1.0.0

Cette version possède la même signature que la v1.0.0.

La v1.0.3 peut donc être installée directement par-dessus la v1.0.0, sans désinstaller l’application.

### Installation

1. Téléchargez `PokeStat-Challenge-1.0.3.apk`.
2. Ouvrez le fichier sur votre appareil Android.
3. Autorisez l’installation depuis cette source si Android le demande.
4. Appuyez sur **Mettre à jour** si une ancienne version est déjà installée, ou sur **Installer** dans le cas contraire.

Une connexion Internet est nécessaire pour récupérer les données et les illustrations des Pokémon.

## 🇬🇧 English

### What’s new

- Added the **Closest** Draft mode
- Victory is awarded when the final score is within **±20 points of the target**
- Added the new Mega Evolutions introduced in **Pokémon Legends: Z-A**
- Added support for Mega **X, Y and Z** forms
- New form filter:
  - Standard
  - Mega
  - Regional
- The **Regional** filter groups the Alolan, Galarian, Hisuian and Paldean forms
- Updated the version number displayed on the home screen

### Changes included since v1.0.0

- **v1.0.1**: added the **Closest** rule to Draft mode. The goal is to finish as close as possible to the target. Victory is awarded when the final difference is 20 points or less.
- **v1.0.2**: added the Mega Evolutions introduced in Pokémon Legends: Z-A.
- **v1.0.3**: grouped the Alolan, Galarian, Hisuian and Paldean forms into a single **Regional** filter.

### Updating from v1.0.0

This version uses the same signing certificate as v1.0.0.

You can install v1.0.3 directly over v1.0.0 without uninstalling the application.

### Installation

1. Download `PokeStat-Challenge-1.0.3.apk`.
2. Open the file on your Android device.
3. Allow installation from this source if Android asks for permission.
4. Tap **Update** if an earlier version is already installed, or **Install** otherwise.

An Internet connection is required to download Pokémon data and artwork.
